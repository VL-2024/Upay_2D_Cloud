# UPAY 2D v0.1.32-alpha

Шаг 1: сцена разделена на два независимых слоя.

## Что сделано
- фон вынесен в отдельный файл: `assets/ref/upay_background_ground.webp`;
- ковер вынесен в отдельный файл: `assets/ref/upay_carpet_round.webp`;
- ковер теперь рендерится отдельным слоем между фоном и игровыми объектами;
- добавлены отдельные настройки позиции и размера ковра;
- центр кучки чуко теперь отдельно настраивается от ковра;
- подготовлена база для привязки физики удара к реальному краю ковра;
- открыт JS API: `UPAY2D.setSceneLayout(...)` для быстрой подстройки позиции ковра и кучки.

## Следующий шаг
На следующем шаге логика удара будет привязана именно к границе ковра, а не к условной области поля.
